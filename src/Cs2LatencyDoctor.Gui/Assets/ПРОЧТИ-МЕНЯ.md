# Как добавить кошелёк для благодарности

Кнопка «♥ Поблагодарить» в главном окне открывает окно с реквизитами.
Сейчас добавлен один кошелёк: **USDT, сеть ERC-20 (Ethereum)**.
Ниже — как добавить второй и последующие.

## Что уже сделано

| Что | Где |
|---|---|
| Адрес кошелька | `DonationInfo.cs`, поле `Address` |
| Сеть для предупреждения | `DonationInfo.cs`, поле `Network` |
| Картинка с QR-кодом | `Assets\usdt-erc20.png` |

## Как добавить ещё один кошелёк

**Шаг 1.** Положите картинку с QR в папку `Assets`, например `usdt-trc20.png`.
Картинку берите прямо из кошелька: «Получить» → «Deposit» → сохранить QR.

**Шаг 2.** Откройте `DonationInfo.cs` и добавьте запись в список `Options`:

```csharp
new DonationOption
{
    Title = "USDT",
    Network = "TRC-20 (Tron)",
    Address = "T...ваш адрес...",
    QrFileName = "usdt-trc20.png",
    Note = "Самая низкая комиссия сети"
}
```

Не забудьте запятую перед `new DonationOption`, если добавляете после существующей записи.

**Шаг 3.** Соберите и запустите проверки:

```powershell
dotnet build -c Release
tests\Cs2LatencyDoctor.GuiTests\bin\Release\net10.0-windows\guicheck.exe --seconds 5
```

Проверки сами сверят формат адреса с указанной сетью и пожалуются, если что-то не так:

- для **ERC-20** и **BEP-20** адрес должен начинаться с `0x` и содержать 40 hex-знаков
- для **TRC-20** адрес начинается с `T` и содержит 34 знака

Это защита от самой дорогой ошибки: адрес одной сети не работает в другой,
и отправка не в ту сеть означает потерю денег.

## Что проверить руками — обязательно

**Наведите телефон на QR в окне программы** и убедитесь, что он открывает
именно ваш кошелёк и адрес совпадает с тем, что показан в окне.

Автоматически распознать QR не получилось: картинки от кошельков приходят
с рамкой, скруглёнными углами и логотипом в центре — для них нужен полноценный
детектор, а тянуть библиотеку ради одной проверки не хотелось. Программа
проверяет формат адреса и пригодность картинки (размер, квадратность),
а совпадение QR с адресом нужно подтвердить глазами один раз.

## Чего программа НЕ делает

- Не напоминает о донате при запуске и не мешает работать.
- Не отправляет наружу ни адреса, ни статистики, ни факта нажатия кнопки.
- Ничего не блокирует за донат: все проверки и исправления бесплатны.
