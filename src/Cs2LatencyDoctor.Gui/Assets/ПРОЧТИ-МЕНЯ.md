# Как включить кнопку благодарности

Кнопка «♥ Поблагодарить» в главном окне уже работает — она открывает окно
с реквизитами. Чтобы окно показывало ваши данные, нужны два шага.

## Шаг 1. Положить QR-код кошелька

1. Откройте свой кошелёк (Trust Wallet, Binance, Bybit, OKX и любой другой)
   и найдите раздел «Получить» / «Deposit» для USDT.
2. Выберите сеть — **ту же, что указана в программе** (по умолчанию TRC-20).
3. Сохраните показанный QR-код картинкой (скриншот или кнопка «Сохранить»).
4. Положите файл в эту папку с именем **`usdt-qr.png`**.

Имя обязательно такое: `usdt-qr.png`. Формат — PNG или JPG (тогда переименуйте,
указав расширение `.jpg` и поправив `QrImageRelativePath` в `DonationInfo.cs`).

Картинка копируется в сборку автоматически: она должна лежать рядом
с `Cs2LatencyDoctor.Gui.exe` в папке `Assets\`.

## Шаг 2. Вписать адрес и ссылку

Откройте `DonationInfo.cs` и заполните три строки:

```csharp
public const string UsdtAddress = "TJ...ваш адрес...";   // адрес кошелька
public const string UsdtNetwork = "TRC-20 (Tron)";       // сеть этого адреса
public const string DonationAlertsUrl = "https://www.donationalerts.com/r/ваш_ник";
```

- **Адрес** показывается в окне и копируется кнопкой «Скопировать адрес».
- **Сеть** показывается рядом. Это защита от ошибки: адрес TRC-20 не подходит
  для ERC-20, и перевод не в ту сеть означает потерю денег. Указывайте честно.
- **Ссылку** DonationAlerts можно не заполнять — тогда кнопка будет неактивна
  и появится пояснение.

## Как это проверить

```powershell
dotnet build -c Release
tests\Cs2LatencyDoctor.GuiTests\bin\Release\net10.0-windows\guicheck.exe --seconds 5
```

Проверки должны пройти. Затем запустите GUI, нажмите «♥ Поблагодарить» и убедитесь,
что QR виден, а адрес копируется.

## Чего программа НЕ делает

- Не показывает напоминаний о донате при запуске и не мешает работать.
- Не отправляет никаких данных: ни адреса, ни статистики, ни факта нажатия.
- Не требует оплаты: все проверки и исправления доступны полностью и бесплатно.
